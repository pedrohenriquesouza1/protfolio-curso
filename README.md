## Processo de desenvolvimento do projeto
Eu desenvolvi esse projeto durante o meu curso de HTML-CSS (esse portfólio foi o último projeto do curso) e naquela época eu não tinha conhecimento nenhum com nenhuma linguagem de programação, tinha apenas 2 meses de curso e estava empolgado para terminá-lo.

Depois de um tempo eu fui revisitando o projeto e fazendo algumas alterações estruturais importantes no projeto, deixando ele mais profissional e util, ao passar do tempo vou alterando mais e mais features e vou atualizar ele sempre, deixando ele com a "minha cara" atual.

Hoje, ele é um organismo vivo que reflete meu domínio atual em:
* Refatoração Estrutural: Migração para práticas modernas de desenvolvimento.

* Arquitetura de Projetos: Organização de código focada em manutenção.

* Design & UX: Aplicação de conhecimentos avançados de CSS para uma experiência fluida.
